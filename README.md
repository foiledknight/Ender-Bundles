**Ender Bundles** is a very straightforward mod which adds bundles that allow you to access your Ender Chest from anywhere. The twist is that so can anyone else if you're not careful. 

**📋 Content**

*   New Ender Bundle Item
*   Player connects to Ender Bundle
*   Recipe for reseting Player connected to Ender Bundle
